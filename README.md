## 📌 Overview

The **AI-Powered Public Welfare Distribution Fraud Detection System** is a Machine Learning based web application designed to identify suspicious welfare distribution transactions.

The system analyzes transaction patterns and predicts whether a transaction is **Safe** or **Fraudulent**, helping to find abnormal activities and improve transparency.

> **Note:** This project is developed for educational and research purposes using a publicly available synthetic dataset.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/sivamanidurgavallampatla/AI-Powered-Public-Welfare-Distribution-Fraud-Detection-System.git
```

```
cd AI-Powered-Public-Welfare-Distribution-Fraud-Detection-System
```

---

## Create Virtual Environment

Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Train Model (Optional)

```bash
python train_model.py
```

---

## Run Application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
